大屏很好，但别把空调给我藏起来

  • 作者：Bougie
  • 创建于：2026-07-05
  • 更新于：2026-07-05
  • 生活
  • 成长

上周从宁波开回上海，走的是沈海高速。那天下雨，不大不小，刚好够让后视镜起雾。

本来这事儿两秒钟就能解决——按一下后视镜加热，或者把空调吹向前挡风玻璃的出风口打开。我以前那辆老车，这俩按钮就在空调面板上并排挨着，闭着眼都能摸到。

但我现在开的是一辆新势力。

那天我伸手去够那个位置，发现空空如也。空调出风口在往脸上吹风，但后视镜还是糊的。我得先在中控屏上找到空调菜单——对，不是在桌面，得先进一级菜单。然后找到"后挡风玻璃加热"，点一下。哦对，旁边还有个"后视镜加热"，但你不确定它是不是和后挡风玻璃联动的。点下去，等了几秒，雾还是没退。

我又低头看了一眼屏幕，发现这两个功能其实在同一个页面，但按钮太小，我刚才点的是"后挡风玻璃"，没点到"后视镜"。再点一次。

等你抬头的时候，车已经往右偏了一点，后面有车按喇叭。

那一瞬间我真的很想把车砸了。

不是说这个操作有多复杂——它其实挺简单的——而是它根本不该这么复杂。后视镜起雾是一个开车过程中随时可能遇到的需求，一个正常人在这种情况下不应该还要分心去看屏幕、去找按钮、去确认自己点没点对。这种"智能化"，是真的让人火大。

# 我那辆"大屏车"

说起来，我现在开的是一辆 2021 年底买的电动车。当时选它，纯粹是因为那块 15 寸的大屏——确实好看，销售演示的时候各种功能都在那块屏幕上，导航、音乐、语音控制，看起来很未来。我甚至觉得，传统车企那种密密麻麻的按钮，简直是老土。

现在想想，真是年轻气盛。

用了这三年，我发现那块大屏最大的作用是：让我在等人的时候可以刷抖音；让我可以在车里唱 KTV；让我可以语音控制天窗。但这些功能，我真正需要它们的时候，十次里有九次都是在停车状态下。

开车的时候呢？语音控制？我试过在高速上用语音调空调，结果识别率感人，特别是车里坐着朋友聊天的时候。或者在地下停车场那种回音很大的环境，语音助手根本不知道你在说啥。手势操作？我不知道是我手势有问题还是车有问题，十次里面能成功两次算我赢。

导航确实用大屏看更舒服，但这不是大屏的功劳，是屏幕尺寸的功劳。倒车影像也是。但这些都是锦上添花的东西，不是我每天开车必须用的功能。

真正每天用的功能是什么？空调、音量、窗户升降、后视镜调节、后视镜加热、方向盘加热、座椅通风。这些东西，我需要在开车的时候快速操作，不需要低头，不需要找菜单，不需要等车机响应。

但现在，这些东西全在屏幕里。

# 说说物理按键的好

我不是在怀念化油器时代。我上一辆车是一辆 2012 年的帕萨特，开了八年，没有任何"智能"可言。但那辆车的功能布局，是我开过的车里最合理的。

空调是旋钮的，往右拧是调温度，往左是调风量。座椅加热是实体按键，一按就开。双跳灯是那种软软的橡胶按钮，位置在中控台正中间，开车时候手自然就能够到。后视镜调节是那种小摇杆，就在主驾驶门板上。

这些设计放在今天看，可能不够"科技"，但对于开车来说，它们是完美的。所有高频使用的功能，都在手边，不需要思考，不需要低头，不需要适应。

我甚至可以在晚上不开灯的情况下，把空调调到合适的温度，把后视镜调正，把窗户关上一半。这不是因为我熟悉那辆车——虽然确实熟悉——而是因为物理按键的位置是固定的，反馈是直接的。

现在的触控大屏呢？每次换一辆新车，我都得花好几天去适应它的菜单逻辑。同一个功能，可能在"设置"里，可能在"空调"里，可能在一个下拉菜单里，可能在一个二级页面里。你得先知道它存在，才能找到它。

这对于日常使用来说，是非常糟糕的体验。

# 大屏流行的逻辑

说了这么多物理按键的好，我得承认，大屏流行的背后是有原因的。

成本是一个绕不过去的因素。物理按键需要开模、需要考虑手感、寿命、防水防尘，需要在不同市场做不同的法规适配。而一块大屏加上一套软件，边际成本几乎为零。一块屏幕可以承载无限的功能，升级只需要 OTA，不需要召回——这对车企来说几乎是完美的商业模式。

视觉上的优势也不能否认。一个简洁的中控台，确实比一堆按钮看起来更"有设计感"。大屏等于科技感等于高端——这个等式虽然粗暴，但在第一眼决策的展厅里，确实有效。我自己当年买电动车，不就是被那块大屏吸引的吗？

还有功能集成。以前空调是空调，导航是导航，收音机是收音机。现在它们可以集成在一个系统里，互相联动——导航说前方两公里右转，空调自动调小音量；出风方向可以根据导航转向调整。这种联动在物理按键时代很难想象。

所以车企做这个选择，有它的商业逻辑。只是这个逻辑，有时候会和用户的实际使用体验产生冲突。

# 风向在变

但是，这两年我注意到一些变化。

最早做出调整的可能是特斯拉。2023 年的某次 OTA 更新之后，Model Y 可以在屏幕上直接显示空调的快捷操作了——虽然还是得进屏幕，但至少不用翻菜单了。而且方向盘上的滚轮也可以控制音量了，虽然不是物理按键，但至少是一种回归。

然后是问界。Mate 60 那波之后，华为在车圈的存在感暴涨。问界 M7 的改款，空调控制区保留了实体旋钮，而且位置就在方向盘旁边，伸手就能够到。这让我觉得这家企业是真的在思考用户怎么用车。

还有领克 08 EM-P。试驾的时候我特意试了一下它的空调控制，发现有实体按键，而且布局很合理。吉利在设计上一直有自己的坚持，这两年开始看到回报了。

极氪 001 也是。2024 款的极氪 001，虽然还是大屏，但把一些高频功能做成了实体按键——比如驾驶模式切换，比如车门解锁。而且极氪的车机 UI 也在改进，常用功能不需要进太深的菜单。

小鹏 G6 我也有关注。那块竖屏设计确实有点反人类，但方向盘上的实体按键救了一些场。而且小鹏的语音控制确实是行业顶尖水准，某种程度上弥补了物理按键的缺失。

这些变化说明什么？说明车企开始意识到，屏幕不是万能药，物理按键的价值被低估了。

# 我自己怎么想

我的判断可能比较朴素：物理按键和屏幕，不是非此即彼的关系。

常用功能——空调、音量、窗户升降、双跳灯——应该用物理按键，或者至少在方向盘附近有实体快捷键。这些功能的使用场景，往往是用户需要快速操作、不想分心的时候。屏幕的多级菜单，在这种场景下是反人类的。

不常用的功能——导航设置、车辆参数调整、第三方应用——可以放在屏幕里。这些功能的使用频率低，用户有时间去翻菜单。

甚至有些功能，用屏幕比用物理按键更好。比如导航地图，用大屏看比用手机支架看舒服多了。比如倒车影像，大屏显示的信息更丰富。

理想的设计，应该是两者的结合。物理按键负责安全相关的操作，屏幕负责信息展示和复杂设置。

但现实是，很多车企走极端了。新势力喜欢搞全屏幕化，传统品牌有的又过于保守。

我自己理想的"智能座舱"，应该是这样的：方向盘上有音量旋钮、驾驶模式切换、语音唤醒按键；中控台有一排空调实体键，温度、风量、前后挡风玻璃除雾、后视镜加热；屏幕负责导航、娱乐、车辆状态显示这些信息密度高的内容；实体开门按键还是要有的，隐藏式门把手在紧急情况下真的可能出问题。

这样的设计，既保留了科技感，又保留了实用性。

# 我不太同意"回归"这个词

有人说这两年是"物理按键的回归"，我不完全同意这个说法。

"回归"这个词暗示着我们在走回头路。但实际上，我们不是在否定大屏，而是在重新思考大屏和物理按键各自的角色。屏幕的价值是客观存在的——它可以显示更多信息，可以升级，可以联动，可以做得更美观。

问题在于，过去几年，行业过于迷信屏幕，把一些不该屏幕化的功能也屏幕化了。现在只是在纠偏。

就像服装行业，喇叭裤、阔腿裤每隔几年就会流行回来，但我们不会说这是"回归"，而是说"轮回"或者"进化"。这次物理按键的回归，也不是简单的重复，而是在屏幕化之后的重新校准。

# 最后说几句

这篇文章有点乱，想到哪儿说到哪儿。但我写它的初衷很简单：作为一个开车十年的人，我想说，车的本质是交通工具，是让人安全、舒适地从 A 点到 B 点的工具。任何设计，都应该服务于这个本质。

大屏很好，但别把空调给我藏起来。语音控制很方便，但别让我在高速上喊三遍它才听懂。隐藏式门把手很酷，但关键时刻打不开车门是要命的。

我希望看到的未来，是物理按键和数字屏幕各司其职、互相补充的未来。不是非此即彼，而是各取所长。

对了，如果你正在选车，我建议你去 4S 店的时候，不要光看屏幕大不大、演示多炫酷。试着在静态情况下把空调调到合适的温度，把后视镜调正，把窗户关上一半，把双跳灯打开。如果这些操作超过十秒，你需要考虑一下。

这是我的标准，可能不适用于所有人。但至少对我来说，一个让我在雨天还要低头找后视镜加热按钮的车，不是好车。

就这样吧。祝大家选车顺利，开车平安。
